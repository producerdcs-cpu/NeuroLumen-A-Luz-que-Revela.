## Detalhamento

### Build 0.1 — Alpha Foundation (Genesis)
**Objetivo:** Fundação documental completa.  
**Entregáveis:** README, Manifesto, Visão, Arquitetura, Design System, Roadmap, Changelog, Contributing, Code Style, License, .gitignore.  
**Critério de conclusão:** Documentação fundamental pronta e validada; estrutura de pastas definida; padrões estabelecidos.

### Build 0.2 — Arquitetura + Skeleton
**Objetivo:** Detalhar ADRs, criar estrutura de monorepo e pastas vazias com READMEs.  
**Entregáveis:** `docs/adr/`, estrutura `apps/`, `packages/`, `backend/`, etc.

### Build 0.3 — Design System
**Objetivo:** Tokens completos, componentes documentados, temas claro/escuro formalizados.

### Build 0.4 — HTML
**Objetivo:** `index.html` extremamente organizado (Header → Hero → Menu → Cards → Timeline → Footer). Sem JavaScript.

### Build 0.5 — CSS
**Objetivo:** `style.css`, `variables.css`, `animations.css`, `responsive.css` separados.

### Build 0.6 — JavaScript
**Objetivo:** Módulos independentes (`main.js`, `navigation.js`, `layers.js`, `animation.js`, etc.).

### Build 0.7 — React
**Objetivo:** Migração para React/Next.js com componentes isolados.

### Build 0.8 — Backend
**Objetivo:** FastAPI, rotas base, estrutura de banco e preparação para IA.

### Build 0.9 — IA + BioData
**Objetivo:** Primeiros módulos de visão, RAG, Knowledge Graph e perfis BioData (Leonardo como piloto).

### Build 1.0 — Publicação
**Objetivo:** Versão pública estável na web (e preparação PWA).
