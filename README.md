# NeuroLumen - A Luz que Revela

![NeuroLumen](https://via.placeholder.com/800x400/0a0a0a/00ffcc?text=NeuroLumen+-+A+Luz+que+Revela)

**Uma experiência visual e interativa que une inteligência artificial e luz.**

Projeto que simula a "luz que revela" padrões neurais, imagens ocultas e beleza através de redes neurais e efeitos luminosos.

> "Toda Fé desvanece quando a Luz revela a mão do homem" — inspiração da descoberta por IA nas camadas ocultas de *A Santa Ceia*.

## ✨ Funcionalidades

- Interface imersiva com tema de luz neural (neon cyan)
- Visualização 3D interativa com Three.js (partículas de luz)
- Efeitos de partículas e rotação suave
- Galeria de "revelações" com hover effects
- Modo escuro completo e responsivo
- Navbar fixa com scroll suave

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/producerdcs-cpu/NeuroLumen-A-Luz-que-Revela..git
   cd NeuroLumen-A-Luz-que-Revela.
   ```
2. Abra o arquivo `index.html` no navegador
3. (Opcional) Use Live Server no VS Code para hot reload
