# ai/

Módulos de Inteligência Artificial do NeuroLumen.

| Subpasta | Foco |
|----------|------|
| `vision/` | Visão computacional (DINOv2, SAM, CLIP, OpenCV) |
| `speech/` | Processamento de voz |
| `llm/` | Modelos de linguagem e RAG |
| `rag/` | Retrieval-Augmented Generation |
| `knowledge_graph/` | Integração com Neo4j e grafo de conhecimento |
| `models/` | Artefatos e pesos (não versionados no git) |
| `training/` | Scripts de treino e avaliação |

Implementação a partir da **Build 0.9**.
