# ADR-001 — Documentação antes de código de aplicação

**Status:** Aceito  
**Data:** 2026-07-30  
**Build:** 0.1 / 0.2

## Contexto

O NeuroLumen é um projeto de longa duração e alta complexidade (IA multimodal, BioData, Knowledge Graph, múltiplas plataformas).

## Decisão

Nenhuma linha de código de aplicação será escrita antes da fundação documental (Manifesto, Visão, Arquitetura, Roadmap, Design System e padrões) estar aprovada.

## Consequências

- Reduz retrabalho e decisões improvisadas.
- Facilita onboarding de colaboradores futuros.
- Mantém o projeto alinhado com rigor científico e ético desde o primeiro commit.
