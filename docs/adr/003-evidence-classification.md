# ADR-003 — Diferenciação obrigatória de tipos de evidência

**Status:** Aceito  
**Data:** 2026-07-30  
**Build:** 0.1

## Contexto

IAs generativas frequentemente apresentam hipóteses como fatos. Isso é inaceitável em um projeto de pesquisa histórica e cultural.

## Decisão

Toda saída da plataforma deve ser classificada como uma das quatro categorias:

1. Fato documentado
2. Inferência
3. Hipótese exploratória
4. Conteúdo criativo

Cada hipótese deve carregar nível de confiança, fontes, evidências e limitações.

## Consequências

- Transparência radical para pesquisadores e público.
- Adequação a museus, universidades e instituições culturais.
- Complexidade adicional na interface e no motor de hipóteses.
